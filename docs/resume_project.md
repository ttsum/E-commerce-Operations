# 简历项目：Olist 电商经营分析与风险预测

## 简历精简版（推荐）

**Olist 电商经营分析与风险预测｜Python / Pandas / Scikit-learn / Matplotlib**

- 基于 Olist 巴西电商 9 张业务表，完成 99,441 笔订单、96,096 位客户和 3,086 家卖家的数据建模；处理多表一对多连接、支付与运费重复计算、日期字段标准化、缺失评价和主外键质量问题，构建订单级、商品级、客户级和卖家级分析数据集。
- 搭建销售、物流、评价和客户指标体系，计算销售额、客单价、月度趋势、品类/地区贡献、取消率、准时/延迟率、配送时长、低评分率、卖家表现和客户复购率；结合 RFM 对客户分层，识别销售额 1,584.36 万、平均客单价 159.33、延迟率 8.11%、低评分率 14.64% 和复购率 3.12% 等关键结果。
- 构建订单延迟和低评分两个预测任务，使用仅在下单/确认时可获得的特征，并按订单时间进行训练/验证/测试切分以避免时间泄漏；对比 Logistic Regression 和 Random Forest，低评分模型测试集 ROC-AUC 最高约 0.60，同时识别出当前下单前特征对延迟预测能力有限，为补充天气、节假日、承运商和区域路由数据提供依据。

## 一句话版本

使用 Python 对 Olist 电商多表数据进行清洗建模、经营指标分析、RFM 客户分层和时间序列预测，输出可复现的数据管线、可视化图表和中文 PDF 分析报告。

## 面试展开版

### 项目目标

从销售表现、物流履约、客户评价和客户价值四个角度分析平台经营情况，并探索订单延迟和低评分的可预测性，为运营、物流和客户维护提供依据。

### 我的工作

1. **数据处理**：区分订单表、订单明细表、支付表和评价表的粒度，使用订单级聚合避免多表连接造成销售额重复；以 `customer_unique_id` 计算复购，保留卖家历史订单量和历史延迟率等不包含未来信息的特征。
2. **指标分析**：建立指标字典，明确每个指标的分子、分母、数据粒度和过滤条件；从品类、州、卖家、支付方式和客户 RFM 等维度定位经营差异。
3. **预测建模**：分别预测“实际送达晚于预计送达”和“评价分数不高于 2 分”，采用时间顺序切分，使用多数类基线、逻辑回归和随机森林，并通过 ROC-AUC、PR-AUC、Precision、Recall、F1 和阈值分析进行评估。
4. **交付与复现**：生成数据质量报告、指标明细、模型结果、图表和中文 PDF；通过自动化测试检查原始文件清单、订单金额加总逻辑和未来信息泄漏风险。

## 简历使用建议

- 如果简历空间有限，使用“简历精简版”的三条内容。
- 如果岗位偏业务分析，保留指标体系、RFM、卖家表现和经营建议。
- 如果岗位偏数据分析/建模，保留时间切分、特征可用时点、数据泄漏控制和模型评估。
- 不建议把延迟预测模型写成“预测效果很好”；当前结果更适合表述为完成建模验证并明确了特征缺口。
